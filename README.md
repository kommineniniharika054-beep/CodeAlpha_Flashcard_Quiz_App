# 📚 Flashcard Quiz App

> **An interactive, browser-based learning application designed to make revision simple, engaging, and efficient.**

The **Flashcard Quiz App** is a lightweight educational web application developed using **HTML5, CSS3, and JavaScript**. It allows users to learn through digital flashcards, reveal answers, navigate between questions, and manage their own collection of study cards.

The application focuses on a clean user experience while providing essential flashcard management functionality such as **adding, editing, deleting, and saving flashcards**.

---

## ✨ Key Features

### 🎯 Interactive Learning

* Display questions and corresponding answers.
* Reveal or hide answers using a dedicated **Show Answer** button.
* Navigate through flashcards using **Previous** and **Next** controls.

### 📝 Flashcard Management

* Add new flashcards with custom questions and answers.
* Edit existing flashcards.
* Delete unwanted flashcards.
* Automatically update the flashcard counter.

### 💾 Persistent Data

* Flashcards are stored using the browser's **Local Storage**.
* Saved flashcards remain available when the application is reopened in the same browser.

### 📱 Responsive Interface

* Clean and minimal user interface.
* Responsive layout for different screen sizes.
* Simple navigation designed for an easy learning experience.
